# Real-Time Surveillance And Tracking System

A comprehensive surveillance and Tracking system with person re-identification capabilities, featuring a Django backend, Electron desktop frontend, and React Native mobile app.

## Project Structure

- **django/**: Django REST API backend with person re-identification using deep learning models
- **frontend/**: Electron.js desktop application for admin dashboard and monitoring
- **mobileapp/**: React Native mobile app for user access and video streaming

## Features

- Person re-identification using YOLOv8 and deep learning
- Real-time video processing and tracking
- User authentication and authorization
- Camera management
- Admin dashboard
- Mobile app for remote monitoring
- Cross-platform compatibility

## Prerequisites

- Python 3.8+
- Node.js 16+
- React Native development environment
- Git

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Real-Time Surveillance And Tracking System
   ```

2. Set up each component following their respective README files:
   - [Django Backend Setup](./django/README.md)
   - [Frontend Setup](./frontend/README.md)
   - [Mobile App Setup](./mobileapp/README.md)

## Usage

1. Start the Django backend server
2. Launch the frontend Electron app
3. Run the mobile app on your device/emulator

## Technologies Used

- **Backend**: Django, OpenCV, PyTorch, YOLOv8, Deep SORT, OSNet, ResNet-50
- **Frontend**: Electron.js, HTML/CSS/JavaScript
- **Mobile**: React Native, Expo
